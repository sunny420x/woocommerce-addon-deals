## Addon Deals สำหรับ Woocommerce ##

สามารถเพิ่มสินค้าเข้าไปใน "ดีลพิเศษ" หรือ Addon Deals ได้ โดยการเพิ่ม slug 'addon-deals' ลงไปในสินค้าเป็นหมวดหมู่ย่อยเพิ่มเติมของสินค้าชิ้นนั้น

## ดีลพิเศษ ##

ปลั้กอินนี้จะลดราคาให้กับสินค้าในหมวดหมู่ Addon Deals จำนวน 10%

## วิธีติดตั้งปลั้กอิน ##
ไปที่ <code>/wp-admin/plugin-install.php</code> และอัปโหลดไฟล์ zip ของปลั้กอิน จากนั้นสามารถ <b>Activate</b> แล้วเริ่มใช้งานปลั้กอินจากเมนูได้เลย !
